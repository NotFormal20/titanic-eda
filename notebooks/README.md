# Анализ выживаемости на Титанике

## Цель проекта
Исследовательский анализ данных (EDA) для выявления факторов, влияющих на выживание пассажиров Титаника.

## Инструменты
- Python 3
- pandas, numpy — обработка данных
- matplotlib, seaborn — визуализация
- Jupyter Notebook (VS Code)

## Данные
Датасет Titanic: 891 пассажир, 12 исходных признаков. После очистки — 11 признаков.

## Ключевые выводы
1. **Пол** — сильнейший фактор: женщины выживали в 4 раза чаще мужчин (74% vs 19%).
2. **Класс** — пассажиры 1 класса выживали в 2.5 раза чаще, чем из 3-го (63% vs 24%).
3. **Взаимодействие пола и класса** — женщины 1 класса: 97% выжили. Мужчины 3 класса: 14%.
4. **Размер семьи** — оптимально 2-4 человека (55-72% выживания). Одиночки и семьи 5+ — реже.
5. **Возраст** — дети выживали чаще, но эффект слабее, чем у пола и класса.

## Структура проекта
- `data/` — исходные и очищенные данные
- `notebooks/titanic_analysis.ipynb` — весь анализ
- `README.md` — описание проекта

## Как запустить
1. Установить зависимости: `pip install pandas matplotlib seaborn`
2. Открыть `notebooks/titanic_analysis.ipynb` в Jupyter или VS Code
3. Выполнить ячейки сверху вниз
